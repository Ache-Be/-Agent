# 教学预警系统 (学生错题-知识点智能分析体)

本项目是一个面向高校程序设计类课程（如 Java）的**学情数据分析与教学预警平台**。它能够自动解析智慧树等平台导出的教学数据，通过多维度聚合分析识别班级及学生的薄弱环节，并配套 AI 教学助手提供智能化建议。

## 一、 项目核心能力

- **多源数据解析**：支持头歌 (CSV)、MOOC (CSV)、随堂测验 (XLSX)、单元练习 (XLSX)、Word 题目 (DOCX) 等多种格式。
- **细粒度分析**：下钻至子任务、考核项与知识点，生成高频易错知识点排行榜。
- **智能预警报告**：自动生成班级汇总报告、单文件报告及学生个人画像。
- **AI 教学助手**：基于 DeepSeek SSE 流式技术，结合真实学情上下文提供教学问答支持。
- **数据管理**：支持文件的增量合并与覆盖模式，具备完善的判重与缓存机制。

## 二、 快速开始

**推荐方式：一键启动**
1. 双击根目录 `start.bat`。
2. 首次运行根据提示输入 `Y` 安装依赖（约 2-3 分钟）。
3. 启动后，浏览器会自动打开 `http://localhost:5173`。

**开发模式：分别启动**
- **后端**：
  ```bash
  cd server
  $env:PYTHONPATH='..;.'
  python main.py
  ```
- **前端**：
  ```bash
  cd frontend
  npm.cmd run dev
  ```

## 三、 测试说明

1. **配置 AI**：进入「系统设置」，配置 DeepSeek API Key 即可启用 AI 教学助手。
2. **数据上传**：
   - 拖拽 `头歌/` 或 `随堂测验/` 文件夹至上传区。
   - **合并模式**：适用于增量添加不同班级或时间的成绩。
   - **覆盖模式**：清空历史数据，完全以当前上传为准。
3. **验证要点**：
   - 检查「预警报告」中的分类是否准确（如个人报告是否已按 `姓名_学号` 规范化）。
   - 验证「学生画像」搜索是否支持班级、年份、姓名等多维度检索。
   - 在 AI 助手问答中确认其是否能准确识别当前上传的班级与实验清单。

## 四、 项目结构

- `server/`：FastAPI 后端，处理业务逻辑、AI 对话及文件管理。
- `frontend/`：Vue 3 + Vite 前端，提供响应式仪表盘与分析界面。
- `analysis/`：核心解析引擎，独立于 Web 框架，负责深度数据挖掘。
- `data/` & `uploads/`：本地存储分析快照、上传副本与生成报告。

## 五、 版本说明

当前版本：**v0.5.0**
- **AI 问答分流架构**（借鉴 Langflow 流式编排思想）：提问先经「意图路由器」分类（成绩个人 / 成绩班级 / 成绩趋势 / 知识点 / 预警 / 考勤 / 报告 / 其他 6 大类），规则优先零成本、LLM 兜底容错，再路由到各自的专用提示词、数据预取与工具子集；分类失败自动降级万能链路，绝不中断。
- **ReAct 自主规划**：工具扩至 6 个（学生成绩、班级聚合、知识点检索、跨实验趋势序列、薄弱知识点、考勤），复杂流程（报告/预警）动态提升工具轮次，模型可自主设计多步任务流程——实测一次报告任务自动完成 6 次工具调用（趋势→薄弱→聚合→对比→成文）。
- **报告 Word 下载**：报告类问答自动将 Markdown 转成 Word 文档，对话内一键下载（独立目录存储，与上传数据隔离）。
- **合并班语义识别**：查询结果自动展开「软件1-3班（合并班：含软件1班、软件2班、软件3班）」等班级粒度标注，AI 会先说明合并班关系再作答，避免数据粒度误解。
- **问答沉淀管理**：设置页支持逐条查看（jsonl + pgvector 双库合并列表）、多选批量删除、一键清空（输入「清空」二次确认）；新增「沉淀参考开关」，可关闭历史问答注入以节省 token。
