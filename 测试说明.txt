======================================================================
一、怎么运行（三种方式，推荐用「方式一：一键启动」）
======================================================================

方式一：一键启动（推荐老师/普通用户用）
----------------------------------------
1. 双击项目根目录 start.bat
2. 首次运行会问「是否安装依赖」选 Y（装 Python 依赖 + 前端 npm 依赖，约 2-3 分钟）
3. 之后会自动：建知识库 → 启动后端（端口 8000）→ 启动前端（端口 5173）
4. 浏览器自动打开 http://localhost:5173

方式二：分别启动前后端（开发/调试时用，分别看日志）
---------------------------------------------------
# 后端 PowerShell：
cd server
$env:PYTHONPATH='d:\A教育agent;d:\A教育agent\server'
python main.py        # 默认监听 0.0.0.0:8000

# 前端 PowerShell（另开一个窗口）：
cd frontend
npm.cmd run dev       # Vite 默认 http://localhost:5173 ，/api 自动代理到 8000

方式三：纯命令行跑分析（不启动 Web，批量跑全部数据）
---------------------------------------------------
python main.py build-knowledge                  # 先建知识库（从章节对应表生成）
python main.py touge  --dir  "头歌\tougeall\智慧树头歌学生学习数据\头歌实验_2026.7.21"
python main.py quiz   --dir  "头歌\tougeall\智慧树头歌学生学习数据\随堂测验"
python main.py mooc   --dir  MOOC
python main.py summary                            # 生成全量汇总 output/summary_report.txt

======================================================================
二、第一步：先配置 DeepSeek API Key（否则 AI 教学助手用不了）
======================================================================
1. 打开 http://localhost:5173
2. 左侧菜单最后一项「系统设置」，找到「DeepSeek API Key」
3. 粘贴你在 https://platform.deepseek.com 申请的 sk-xxxx 开头的 Key
4. 点「保存设置」→ 成功后字段会变成「***** 已配置（留空不修改）」
5. Key 真实存储位置：server/config/settings.json（纯本地磁盘，不会上传任何第三方服务器）

三、能做什么（功能清单 + 测试入口位置）
======================================================================
| # | 功能 | 测试入口（菜单） | 预期 |
|---|------|------------------|------|
| 1 | 数据上传（合并 / 覆盖两种模式） | 左侧「数据上传」 | 支持拖拽文件夹 / 多选文件；页面下方分 3 块 alert：主信息（蓝）/跳过重复（黄）/校验失败（红），不再笼统报「格式错误」 |
| 2 | 仪表盘总览 | 左侧「首页」 | 学生数、实验数、薄弱率、预警学生卡片；最近报告 Top 列表可直接预览 |
| 3 | 预警报告（综合汇总/单文件/学生个人/题目） | 左侧「预警报告」 | 5 个 Tab 秒切（平均 <20ms，无需等扫盘）；右上角搜索框支持「姓名/学号/班级/年份」全文检索，支持预览/下载 |
| 4 | 学生画像列表 + 详情 | 左侧「学生画像」 | 薄弱率进度条（红黄蓝三色一眼可见）；重点预警学习建议只保留「谈话+家长沟通」两条，已删除老师没时间的「一对一辅导最薄弱3个单元」 |
| 5 | AI 教学助手（流式 SSE） | 左侧「AI 教学助手」 | DeepSeek 流式响应；自动注入班级清单/年份清单/实验清单；支持问「软件 2 班 2026 年成绩怎么样」，不会编造不存在的班级 |
| 6 | 对话重命名 / 删除 | 左侧 AI 教学助手，每条对话右侧「⋯」按钮 | hover 出现 MoreFilled 三点图标；点击弹框：重命名（PATCH）/删除（DELETE）；存储在后端磁盘 server/data/conversations/，清浏览器缓存也不丢 |
| 7 | 数据文件管理 | 左侧「数据文件」 | 全部已上传文件列表，支持搜索、单个删除（会同步清理关联分析结果） |
| 8 | 系统设置（阈值 + API Key） | 左侧「系统设置」 | 薄弱阈值/低分线/查答案率关注线 + DeepSeek Key，全部真写入 server/config/settings.json，重启服务后依然保留 |

======================================================================
五、注意事项 & 常见问题
======================================================================
1. 项目内已经包含全部真实原始测试数据（D:\A教育agent\头歌\、MOOC\、word+excel+pdf\），
   可以直接拿上面的 4 个必测用例 + 2 个回归用例测效果，无需额外找数据；
2. 覆盖模式会真正清空：server/uploads/* 与 server/uploads/reports/*.txt / *.csv
   + 内存分析结果 + 报告列表缓存 + 保存快照，所以点覆盖前确认好是否要保留历史；
3. 合并模式智能判重：同名不同班级（如 1-3 班 vs 4-5 班的「项目0-Java语言概述.xlsx」）
   绝对不会丢；只有内容字节级完全相同的文件才会跳过；
4. 所有学习建议里的「一对一辅导最薄弱的 3 个单元」已全部删除，
   只保留「老师单独谈话确认学习态度与出勤」+「必要时与家长沟通近期学习状况」两条；
5. 对话记录存储位置：server/data/conversations/conv_{uuid}.json（后端磁盘 JSON），
   最多自动保留 50 个，超过自动清理最旧的；换电脑只要复制这个文件夹对话就能带走；
6. 分析结果仅供参考，请以实际教学情况为准；
7. 如有问题欢迎随时反馈，我们会在 1 个工作日内修复。
